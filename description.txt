# 🌍 Geospatial Image Tagging using Natural Language

## 📌 Description

This project is a **standalone spatial application** that enables **semantic tagging and retrieval of georeferenced images using natural language**.

It combines:

* Computer Vision 🧠
* Natural Language Processing 💬
* Vector Databases 🔎
* Geospatial filtering 🌍

Users can search images using queries like:

> "residential area with trees near Tunis"

---

## 🚀 Features

* 📷 Store georeferenced images (latitude, longitude)
* 🧠 Generate embeddings from images and text
* 🔎 Semantic search using natural language
* 🌍 Spatial filtering (radius, location)
* 🏷️ Automatic image tagging (optional)

---

## 🧱 Tech Stack

### 🧠 AI / NLP

* OpenAI CLIP (image-text embeddings)
* spaCy (text preprocessing)
* BLIP (optional image captioning)

### 🗄️ Databases

* ChromaDB (vector database)
* PostgreSQL + PostGIS (geospatial queries)

### ⚙️ Backend

* FastAPI (REST API)

### 🧰 Tools

* OpenCV / Pillow (image processing)
* Docker (containerization)

```json
  "lon": 10.1,
  "radius": 5
}
```

---

## 🧠 How it works

1. Images are encoded using CLIP → embeddings
2. Text query is encoded into the same vector space
3. Similarity search is performed in ChromaDB
4. Results are filtered using geospatial constraints (PostGIS)
